## How to use

- Browse categories in the table above or open [TOOLS.md](TOOLS.md) for repository links, primary use cases, licenses, languages, and factual notes.
- Read [data/tools.csv](data/tools.csv) directly if you need structured CSV input for scripts or analysis.
- After modifying `data/tools.csv`, regenerate the Markdown files locally with Python 3 (standard library only):

```bash
python scripts/generate.py
python scripts/generate.py --check
```
